# 青春連線不迷網：中小學生數位素養與網路法治冒險
> **Youth Cyber Adventure: Interactive Digital Citizenship & Netiquette Quest**

專為國小高年級至國中學生設計的**互動式多結局數位素養教材網頁**。透過「Choose-Your-Own-Adventure（4選1多故事分支）」的沉浸式角色扮演模式，讓孩子在面對誘惑、衝突與同儕壓力時親自做出抉擇，深刻體會網路成癮、言論霸凌、公然侮辱與個資法律責任。

---

## 🌟 核心特色與教學亮點

1. **4 選 1 多情境心理分支**：
   - 🅰️ **衝動型**（追求當下快感、發洩情緒）
   - 🅱️ **跟風/妥協型**（隨波逐流、看熱鬧不嫌事大）
   - 🅲️ **焦慮/逃避型**（以短影音逃避、退縮壓抑）
   - 🅳️ **覺察/理智型**（停頓換位思考、堅守原則並尋求協助）
2. **即時三維狀態儀表板**：
   - 🔋 **精力與理智值（Sanity & Energy）**
   - ⚖️ **法律安全值（Legal Safety）**
   - 🤝 **同儕友誼值（Relationship）**
3. **兩大主線故事單元**：
   - **🎮 深夜的排位賽與黑眼圈（成癮防制篇）**：探討深夜手遊開黑、短影音演算法沉迷、睡眠剝奪、同儕焦慮（FOMO）與自律。
   - **💬 班級群組裡的神秘截圖（言論法治篇）**：探討偷拍出糗照外流、改圖公然侮辱、未經同意散播個資、旁觀者效應與少年法庭傳票危機。
4. **法律白話小百科與結尾複盤錦囊**：
   - 刑法第 309 條【公然侮辱罪】
   - 刑法第 310 條【加重誹謗罪】
   - 個人資料保護法（非法利用個資、肉搜）
   - 民法第 187 條【法定代理人（父母）連帶損害賠償責任】
   - 兒童及少年性剝削防制條例
   - 免費求助資源（教育部 1953 反霸凌專線、iWIN 網路內容防護機構、兒福聯盟 0800）
5. **數位挑戰證書生成**：
   - 挑戰完成後可自訂輸入學生姓名與班級，生成專屬榮譽證書並支援一鍵列印/另存 PDF，方便課堂成果驗收。
6. **零依賴・極速載入**：
   - 純前端單頁架構（HTML5 + Tailwind CSS + Web Audio API 原生音效合成），無須後端伺服器與資料庫，不收集學生隱私個資，支援 Chromebook、iPad、手機與個人電腦。

## 🏫 教學現場使用建議（40分鐘一堂課）

| 時間 | 環節 | 說明 |
| :--- | :--- | :--- |
| **0 ~ 5 分鐘** | 引起動機 | 提問學生：「有沒有人在深夜被朋友狂叩打遊戲過？班群裡有沒有傳過同學出糗照片？」 |
| **5 ~ 20 分鐘**| 自由互動闖關 | 請每位學生使用平板或手機進入網頁，各自體驗兩套劇本（鼓勵嘗試踩踩看地雷選項）。 |
| **20 ~ 30 分鐘**| 數據統計與討論 | 統計全班有多少人拿到「少年法庭傳票結局」或「考場崩潰結局」？討論哪個選項最難以抗拒。 |
| **30 ~ 38 分鐘**| 法律法規總結 | 點擊「法律小百科」，講解公然侮辱與家長連帶賠償的真實案例。 |
| **38 ~ 40 分鐘**| 頒發榮譽證書 | 學生生成專屬稱號證書，截圖上傳學習平台完成作業。 |

## 🛠️ 本地執行與開發

本專案無需安裝複雜環境，直接在瀏覽器開啟 `index.html` 即可運行。

```bash
# Clone 儲存庫
git clone https://github.com/clive520/youth-cyber-adventure.git

# 開啟網頁
cd youth-cyber-adventure
start index.html   # Windows
# open index.html  # macOS
```
