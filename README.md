# 微光與暗潮：青少年數位言論與網路生活抉擇
> **The Unseen Currents: An Interactive Scenario-Based Learning Experience on Cyber Ethics, Netiquette & Digital Well-being**

專為國小高年級至國中階段學生設計的**深度情境式互動數位素養教材**。摒棄非黑即白的說教方式，以一場發生在班級私密群組與校園日常的真實衝突為核心，引導學生在同儕壓力、被孤立的恐懼、逃避現實的誘惑中進行多階段深層思考。

---

## 🌟 核心革新與設計理念

### 1. 拒絕劇透標籤，回歸自主思辨
* **去除一切數值劇透與引導標籤**：以往許多教材會在選項旁標註「+10 法律」或「衝動型/正義型」，這往往讓學生失去自主思考，直接挑選「看起來最正確」的選項。
* 本教材的每一個選項均採用青少年面對當下情境時**真實浮現的內心獨白或行為反應**，沒有預先劇透的好壞提示，促使學生必須自己權衡代價、換位思考並承擔後果。

### 2. 多層次遞進的沉浸式敘事（5～7 階段連續抉擇）
故事並非「選擇一次就草草結束」，而是具備完整的戲劇張力與因果網絡：
* **第一幕【幽微的漣漪】**：午休私密班群裡流傳的醜照，該跟著起鬨、私訊提醒、跟死黨八卦，還是沉默裝死？
* **第二幕【暗流湧動】**：照片演變成公開 IG 迷因帳號，走廊上的異樣眼光、同儕陣營的猜忌與對立。
* **第三幕【深夜的虛擬避難所】**：白天人際壓力的後座力——是用手遊排位、短影音演算法無意識逃避？還是深夜與家人敞開心扉？
* **第四幕【引爆的風暴】**：家長提告、少年警察隊與律師介入、或輔導老師早晨的主動關懷，衝突抵達臨界點。
* **最終章【多重命運結局與深度複盤】**：依照玩家的所有決策軌跡，收束至 6 種截然不同的人生結局。

### 3. 六大多維度深度結局與教育複盤
1. ⚖️ **【少年法庭的傳票與家庭風暴】**（刑法公然侮辱罪、加重誹謗、個資法、民法第 187 條法定代理人連帶賠償）
2. ⏳ **【虛擬避難所的代價與失序生活】**（逃避型成癮心理、演算法藍光與褪黑激素抑制、前額葉自控力瓦解）
3. 🌫️ **【旁觀者的長夜與難言的愧疚】**（旁觀者效應 Bystander Effect、群體責任分散、道德自我貶抑）
4. 🤝 **【勇敢認錯的真誠和解】**（修復式正義 Restorative Justice、司法實務中主動面對與和解的價值）
5. 🌱 **【安靜的守護者・風暴中的避風港】**（數位同理心 Digital Empathy、打破受害者的孤立無援）
6. 🏛️ **【破局的勇氣・卓越數位公民】**（批判性獨立思考、善用 iWIN 與校園機制、堅定維護善良）

## 🏫 課堂引導與教學建議

* **適合對象**：國小五～六年級、國中七～九年級班會課、綜合活動領域、公民與社會、資訊科技素養課。
* **分組探討活動**：
  1. 請學生個別用手機、平板或電腦進行遊玩（約 10~15 分鐘）。
  2. 統計全班達成的各項結局分布。
  3. 提問：「你在哪一步感到最掙扎？如果明知道某個做法不對，現實中有什麼原因會讓你還是忍不住想選它？（如：害怕被朋友排擠、好奇心、想發洩）」
  4. 引導學生點閱「法律觀點」，了解真實少年事件處理流程與家長連帶民事賠償責任。
  5. 頒發或截圖「數位公民思辨歷程證書」。
